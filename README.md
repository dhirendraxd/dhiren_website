# Ismail - Designer Portfolio

A modern, minimalist portfolio website for Ismail, a creative designer specializing in branding, UI/UX design, and graphic design.

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ or Bun

### Installation

```bash
npm install
# or
bun install
```

### Development

```bash
npm run dev
# or
bun run dev
```

The site will be available at `http://localhost:8081` (or next available port)

### Build

```bash
npm run build
# or
bun run build
```

### Preview

```bash
npm run preview
# or
bun run preview
```

## 🎨 Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/UI (Radix UI)
- **Animations**: Framer Motion
- **Routing**: React Router
- **State Management**: React Query
- **Forms**: React Hook Form + Zod

## 🎯 Features

- Modern, minimalist design
- Smooth animations with Framer Motion
- Responsive layout
- Eye-friendly off-white color palette
- Portfolio showcase
- Services listing
- Contact form
- Social media links
- Fast performance with Vite
